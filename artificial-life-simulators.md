# Artificial Life Simulators — Master List

A comprehensive catalog of artificial life / evolution simulators, both on and off Steam.

Already known: Planetary Life, The Bibites, ANLife: Motion Learning Life Evolution.

---

## On Steam

| Name | Description |
|------|-------------|
| [Species: Artificial Life, Real Evolution](https://store.steampowered.com/app/774541/) | Scientifically-grounded natural selection sim; creatures evolve and speciate in real-time |
| [Thrive](https://store.steampowered.com/app/1779200/Thrive/) | Open-source, scientifically-accurate Spore successor; starts at unicellular stage |
| [Ecosystem](https://store.steampowered.com/app/1133120/Ecosystem/) (Slug Disco) | Neural-network sea creatures evolving in physics-simulated ocean |
| [The Sapling](https://thesaplinggame.com/) | Design plants/animals with evolution & mutation, watch ecosystems interact |
| [Gridworld](https://store.steampowered.com/app/396890/Gridworld/) | 2D grid-based neural-net creatures competing for survival |
| [Vilmonic](https://bludgeonsoft.org/) | Deep pixel-art alife sandbox with DNA system and evolution tree |
| [Artificial Life Simulator](https://store.steampowered.com/app/2805670/) | Particle-interaction-based emergent lifeforms |
| [Niche – a genetics survival game](https://store.steampowered.com/app/440650/) | Turn-based real genetics (dominant/recessive) with cat/fox-like animals |
| [Equilinox](https://equilinox.com/) | Low-poly ecosystem with genetic modification of species |
| Creatura | Darwin/Mendel-based natural selection and genetic engineering |
| Small Living World | Place plants/animals/soil/water to build ant-farm ecosystems |
| The Monster Breeder | Lamarckian stat breeding with appearance blending |
| Mendel | Manual plant genetics breeding puzzle |
| Crazy Plant Shop | Selective plant breeding to fill orders |
| [Planetary Life](https://store.steampowered.com/app/2471970/) | Planet-scale sandbox, cells → civilizations (already known) |

## Cellular Automata / Particle Alife

| Name | Description |
|------|-------------|
| [Lenia](https://chakazul.github.io/lenia.html) (Bert Wang-Chak Chan) | Continuous generalization of Conway's Game of Life; 400+ "species" |
| [Flow-Lenia](https://sites.google.com/view/flowlenia/) | Mass-conservative extension, multi-species capable |
| Particle Life (Tom Mohr) | Attraction/repulsion emergent patterns |
| [Clusters](https://www.ventrella.com/Clusters/) (Jeffrey Ventrella) | Asymmetric particle system that inspired Particle Life |
| [Primordial Particle Systems (PPS)](https://zool33.uni-graz.at/artlife/PPS) | Self-reproducing life-like cells from simple motion law |
