**Written 13 October 2026 on the laptop (minty).** The desktop's copy of `desktop-setup/` is now behind this one.
The corrections from `findings-and-tests/findings/REVIEW-2026-10-13.md` were applied here and both PDFs rebuilt.
The desktop still holds the uncorrected sources, so if it runs `_build/experiment-s7/assemble.sh` again it will

**Do this before any more work on the paper on the desktop.** Nothing about the simulations, runs, data or
checkpoints changed; this is text only.

## The quick way: one zip

`desktop-sync-2026-10-13.zip` (beside this file, and a copy on the laptop's Desktop) holds exactly the 22 changed
files, laid out relative to `desktop-setup/`, plus this file and a checksum list.

1. Copy `desktop-sync-2026-10-13.zip` to the desktop (USB stick, network share, or however the big zip came across).
2. On the desktop, unzip it **over** `desktop-setup/`, replacing what is there:

   ```bash
   cd /path/to/desktop-setup                 # the folder holding _build/, findings-and-tests/ and the PDFs
   unzip -o /path/to/desktop-sync-2026-10-13.zip
   ```

3. Check every file arrived intact (all 22 lines must say `OK`):

   ```bash
   sha256sum -c SYNC-SHA256.txt
   ```

4. Prove the sources and the PDFs agree. This rebuilds the paper from the corrected sources; the screen PDF must
   come out at 35 pages and the print PDF at 36:

   ```bash
   cd _build/experiment-s7 && bash assemble.sh
   cd ../.. && pdfinfo River-World-Desktop-Setup.pdf | grep Pages && pdfinfo River-World-Desktop-Setup_print.pdf | grep Pages
   grep -c "about 12% sooner" River-World-Desktop-Setup.md      # must print 1: the corrected text is in
   ```

5. Done. Delete the sync zip, and `SYNC-SHA256.txt` and this file if you like.

## If something goes wrong

- **A checksum fails:** the copy was damaged in transit. Copy the zip again and repeat from step 2.
- **The page counts differ** (not 35 and 36): the desktop has edits the laptop does not know about. Do not
  overwrite them; compare with `diff -r` against the zip's files and merge by hand.
- **To go back:** the edition before these corrections is kept on the laptop in
  `_superseded/2026-10-13-desktop-35pp/`, and the desktop's own zip, `desktop-setup-finished.zip`, is untouched.
